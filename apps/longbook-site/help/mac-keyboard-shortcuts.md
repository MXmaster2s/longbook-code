# Mac keyboard shortcuts

- Page: https://longbook.app/help/mac-keyboard-shortcuts/

## Go to a screen

| Shortcut | Screen |
|---|---|
| ⌘1 | Dashboard |
| ⌘2 | Reports |
| ⌘3 | Calendar |
| ⌘4 | Commitments |
| ⌘5 | Insights |
| ⌘6 | Proposals |
| ⌘7 | Trips |
| ⌘[ | Back |

## Do something

| Shortcut | Action |
|---|---|
| ⌘N | New Commitment |
| ⌘I | Import Statement… |
| ⌘, | Settings… |
| ⌘? | longbook Help |

## In the Settings window

| Shortcut | Action |
|---|---|
| ⌘[ | Back |
| ⌘] | Forward |

In sheets and forms, Return confirms and Escape cancels.

## In the menu bar

The longbook menu also has **Check for Updates…** and **Tips**. The **Settings** row at the foot of the sidebar opens a menu with **Settings…**, **What’s New**, **Send Feedback…**, **Check for Updates…** and **Quit longbook**.

The longbook item in the Mac menu bar shows your next payment. Its menu has **Open longbook**, **Refresh** and **Quit longbook**. See "The widget and the Mac menu bar".

Still have a question? Tap **Support** in the corner of any screen in the app, or write to contact@longbook.app and a person answers.
