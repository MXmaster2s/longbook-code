# Work on the source

> longbook is licensed GPL-3.0, and its source code is public on GitHub: read it, build it, and send a pull request.

- Page: https://longbook.app/source/

longbook is licensed under **GPL-3.0**, and its source code is public on GitHub: the iPhone and Mac apps, the MCP server, the website and the server functions, in one repository.

HOW TO HELP

Read it, build it, and open an issue or a pull request at [github.com/MXmaster2s/longbook-code](https://github.com/MXmaster2s/longbook-code). Bug fixes, hardening and building on top of longbook are all welcome.

[Open the repository](https://github.com/MXmaster2s/longbook-code)

The work is coordinated on the [community Discord](https://discord.gg/28Dtvbx23q) — feature requests, the roadmap, and who is building what.
