# longbook for iPhone

> longbook for iPhone is in beta through TestFlight, Apple's own app for trying apps before they reach the App Store. Two steps: install TestFlight, then open the invitation.

- Page: https://longbook.app/ios/

The iPhone app is in beta, so it arrives through **TestFlight** — Apple’s own app for trying apps before they reach the App Store. It is two steps, and both are free.

1. ## Install TestFlight

   It is Apple’s app, from the App Store. If you already have it, skip this step.

   [Get TestFlight](https://apps.apple.com/app/testflight/id899247664)
2. ## Open the invitation on your iPhone

   [Open the invitation](https://testflight.apple.com/join/g66Nd3Na)

   Open it on the phone you want longbook on. It opens TestFlight and accepts the invitation for you — there is no code to type.
3. ## Install longbook, and open it

   TestFlight shows longbook with an Install button. From then on it behaves like any other app on your phone, and TestFlight tells you when a new build is ready.

**On a Mac instead?** The same invitation works there: install [TestFlight for Mac](https://apps.apple.com/app/testflight/id899247664) from the Mac App Store, then open the invitation. One purchase covers every platform.

**Nothing arrived, or the link will not open?** The invitation has to be opened on the iPhone itself, not on a computer. If it still does not work, [get support](https://longbook.app/support/) or write to [contact@longbook.app](mailto:contact@longbook.app) and it gets sorted.
