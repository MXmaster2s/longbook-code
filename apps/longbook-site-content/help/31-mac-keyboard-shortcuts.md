# Mac keyboard shortcuts

## Go to a screen

| Shortcut | Screen |
|---|---|
| ⌘1 | Dashboard |
| ⌘2 | Reports |
| ⌘3 | Calendar |
| ⌘4 | Commitments |
| ⌘5 | Insights |
| ⌘6 | Proposals |
| ⌘7 | Trips |
| ⌘[ | Back |

## Do something

| Shortcut | Action |
|---|---|
| ⌘N | New Commitment |
| ⌘I | Import Statement… |
| ⌘? | longbook Help |

In sheets and forms, Return confirms and Escape cancels.

## In the menu bar

The longbook menu also has **Check for Updates…** and **Tips**.

The longbook item in the Mac menu bar shows your next payment. Its menu has **Open longbook**, **Refresh** and **Quit longbook**. See "The widget and the Mac menu bar".
